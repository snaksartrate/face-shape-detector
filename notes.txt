pipeline:
camera -> frame capture -> face detection -> landmark extraction -> proportion calculation -> classify shape -> display on frame -> show video

step 1: get a stream of images as input
step 2: crop or locate the face
step 3: locate specific facial features
step 4: compute ratios and determine shape
step 5: write on the captured image with a textbox near the face that displays the face shape
step 6: display

detailed idea:

project/

main.py
    choose mode (rb/ml)
    initialize camera
    initialize landmark detector

    while True:
        frame = get_frame()
        faces = detect_face(frame)

        for face in faces:
            landmarks = extract_landmarks(face)

            if mode == "rb":
                shape = rb.classify(landmarks)

            else:
                shape = ml.classify(landmarks)

            overlay(shape)

        display(frame)
